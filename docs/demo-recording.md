# RepoScope 演示录制指南

## 当前可录内容

Task 7 只能录制静态产品流程占位 Demo。画面必须持续显示“预生成演示”“产品流程演练”“非真实分析/非 benchmark”提示，不能把 `example/*` 仓库描述成真实历史项目。

真实模型演示只能在完成数据核验并本地运行后单独录制；不得展示 API Key、`.env`、Authorization header、Issue 私密信息、本地绝对路径或 hidden gold。

## 60 秒 GIF 脚本

1. 0–8 秒：标题与一句价值主张；
2. 8–18 秒：输入仓库 URL 与 Issue 的表单，但不提交真实调用；
3. 18–32 秒：进入“预生成演示”，播放调查事件；
4. 32–48 秒：查看证据、根因候选、影响文件与测试建议；
5. 48–60 秒：展示静态只读、安全边界与本地运行入口。

## 3–5 分钟讲解

按“问题 → 产品流程 → 架构 → 安全 → 评测 → 局限”讲解。明确说明为什么不是普通 RAG、为什么 Agent 只有只读工具、引用如何校验、为什么公网 Demo 不连接模型，以及当前尚无真实 benchmark 成绩。

## 录制前检查

- 使用全新浏览器资料或无敏感书签的窗口；
- 清空终端历史和通知，隐藏用户名与本地路径；
- 浏览器缩放 100%，分别检查桌面和 360 px 视口；
- 静态构建下用开发者工具确认 Demo 播放没有 API/model 请求；
- 只展示通过当前测试的行为；
- 导出后完整回看，检查字幕、密钥、路径、占位标签和音频。

最终媒体文件是否提交、压缩规格和链接有效性在 Task 8 发布候选检查中确认。
